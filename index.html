About the studio

WizardRobin is an indie game studio focused on modular, scalable systems for Unreal Engine 5. Our belief is simple: build the systems first, and the rest of the game gets easy.

Our team built GenesisCore, an Unreal Engine 5.8 game template available on Fab, and shipped it with full documentation and a tutorial video series. The same architecture-first approach now powers our own game, Callidice.

Alongside our own projects, the studio helps asset creators, plugin makers and small teams do the same: clear structure, honest documentation and a polished presentation, delivered fast without cutting corners.
